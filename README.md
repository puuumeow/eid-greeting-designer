# SalamiAoo – Eid Greeting Designer

A creative mobile application prototype developed using MIT App Inventor to create and share personalized Eid greeting messages.

## Overview

SalamiAoo is a mobile application designed to make sharing Eid greetings more interactive and personalized. It features themed screens and customizable messages, allowing users to create greeting content for friends and family.

## Features

- Customizable greeting messages
- Themed interface designs
- Separate bKash and Nagad-inspired visual themes
- Message input and editing
- Save and share functionality
- Multi-screen navigation

## Technologies Used

- MIT App Inventor
- Visual programming with blocks
- User interface design
- Android application development
